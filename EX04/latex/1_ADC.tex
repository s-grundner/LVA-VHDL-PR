\textbf{Architecture}

The ADC uses a PWM Module and a Sampling-Strobe-Generator. Other than that it
is described by three processes.

\textbf{Signals}

\lstinputlisting[firstline=16,lastline=19,gobble=auto]{../delta_adc_a.vhd}

(1) \lstinline{adc_reg : process (clk_i, rst_i)} 

\begin{quote}
    The register process determines the clock and reset behavior. On the rising
    edge the next combinatorially determined ADC state is assigned to the ADC
    output, which is the duty cycle counter value \lstinline{ON_counter_val} of
    the PWM generator. On reset, the ADC output is set to \lstinline{'0'}.
\end{quote}

(2) \lstinline{adc_comb : process (sampling_strobe, Comparator_i)}

\begin{quote}
    The combinatorial logic necessary for determining the ADC value is described
    here. Assuming that the \lstinline{sampling_strobe} is \lstinline{'1'}, the
    following applies: If the input value \lstinline{Comparator_i} delivered by
    the comparator is \lstinline{'1'}, the duty cycle is incremented by 1, otherwise
    it is decremented. Additionally, with each \lstinline{sampling_strobe}, the
    current comparator state is stored, which is relevant for the validation of the
    ADC value.
\end{quote}

(3) \lstinline{validate_comb : process (Comparator_i, prev_comp)}

\begin{quote}
    The ADC has an \lstinline{ADC_valid_strb_o} output, which indicates whether
    the actual ADC value is present at the output, meaning the settling process
    is complete. In this implementation, this state occurs if the comparator
    value reverses. If the comparator value has been \lstinline{'1'} for several
    sampling periods and suddenly becomes \lstinline{'0'} (and vice versa), then the
    PWM average value in the last sampling period has reached the analog value,
    and the correct value is approximately present at the ADC output. 
\end{quote}
    
\subsection*{Simulation}

\textbf{ADC-Test}

Here, the comparator input is emulated by setting it to 1 in the stimulus process after
a certain time. During this time, you can see how the duty cycle of the PWM signal
increases and, as expected, decreases again with the switching of the comparator input.
In the sampling period shortly after the switch, it can also be seen how the ADC valid
strobe goes high. 

\begin{center}
    \includegraphics[width=1\linewidth]{images/SIM_ADC1.png}
\end{center}

In this waveform, the ADC value would be 1101.
